# jiggle_wiggle_of_atoms

An Expandable Molecular Dynamic simulation Engine

## The Molecular Dynamic Simulation (MDS)

A Deterministic Molecular Simulation with Newtonian Equation of Motion for Classical Particles (in classical MD), interacting with classical/machine learning or even more complicated Force Fields, confined in a box with initialized position and velocities. In short terms, an Engine for jiggling and wiggling atoms.
